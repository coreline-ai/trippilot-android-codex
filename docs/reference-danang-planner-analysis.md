# 다낭 여행 플래너 참조 분석 및 TripPilot 적용 원칙

작성 일시: `2026-08-16 21:25:37 KST`

참조 대상: [다낭 4일 여행 플래너](https://share.onorca.dev/a/YVOJdG3zPq6U)

이 문서는 참조 페이지의 **정보 구조와 사용성 패턴**을 분석한 것이다. HTML·CSS·JavaScript·사진·지도·문구를 복사하거나 앱에 포함하는 구현 지시가 아니다. TripPilot은 자체 Kotlin/Compose 코드와 자체 문구·시각 자산만 사용한다.

## 한 줄 평가

참조 페이지의 장점은 여행을 단순 일정 목록이 아니라 **출발 전 → 일자별 진행 → 문제 발생 시 → 귀국 후**의 시간 흐름으로 관리하고, 준비 항목마다 “왜 필요한지”가 함께 보인다는 점이다. TripPilot에는 이 구조를 로컬 우선·사용자 승인 원칙에 맞춰 적용한다.

## 출발 전 준비물: 참조 구조를 일반화한 TripPilot 기본 팩

참조 페이지는 29개의 체크 항목을 5개 그룹으로 나누고, 각 항목에 짧은 이유·확인 방법을 붙인다. TripPilot의 `INTERNATIONAL` 기본 팩은 아래처럼 **특정 국가의 사실을 단정하지 않는 일반형 문구**로 구성한다.

| 그룹 | 기본 항목 예시 | 항목별 안내 원칙 |
|---|---|---|
| 서류·입국 | 여권 상태, 입국 조건/비자, 왕복 이동 증빙, 숙소 확인서, 여행 보험, 사본·비상연락처 | 유효기간, 비자, 입국 요건은 국가·국적·시점에 따라 달라 “공식 출처에서 직접 확인”으로 표시한다. |
| 결제·현금 | 결제 카드 2장, 해외 사용 설정, 현지 결제 수단/소액 현금, 카드 분실 연락처 | 특정 카드사·환율·현금 금액을 기본값으로 강요하지 않는다. |
| 통신·전자기기 | eSIM/유심 또는 로밍, 충전기, 보조배터리, 어댑터, 오프라인 지도, 교통 앱, 방수/보관 수단 | 배터리 기내 반입·플러그 규격 같은 기준은 출처를 사용자가 연결해 재확인할 수 있게 한다. |
| 의류·현장 용품 | 기후에 맞는 의류, 얇은 겉옷, 걷기 편한 신발, 우천/햇빛 대비, 보조 가방 | ‘필요 시’인 항목은 기본 완료율을 불필요하게 낮추지 않도록 선택 팩으로 분리한다. |
| 건강·위생 | 평소 복용약, 기본 상비품, 자외선/벌레/위생 대비 | 의료 조언이나 처방을 제공하지 않는다. 개인별 복용약과 현지 의료 정보는 사용자가 직접 기록한다. |

## 참조 화면에서 가져올 UI 원칙

1. **단계가 곧 내비게이션이다.** 출발 전과 일자별 일정을 한 줄의 여행 단계로 읽게 한다.
2. **체크리스트는 제목만 두지 않는다.** 기본 항목에는 짧은 목적·확인 기준을 붙인다.
3. **일정은 시간표가 아니라 현장 브리프다.** 시간·장소·종류·사용자 메모가 한 덩어리로 보인다.
4. **예약은 여행 서류처럼 읽는다.** 예약처, 상태, 확인번호, 시간·장소, 연결 출처를 한 눈에 묶는다.
5. **긴급 정보는 평상시 화면을 방해하지 않는다.** 그러나 오프라인에서 즉시 열 수 있게 별도 진입점에 둔다.
6. **진행률은 다음 행동을 가리킨다.** 단순 퍼센트 대신 미완료 그룹과 가장 가까운 행동을 함께 보여 준다.

## 적용하지 않는 내용

- 참조 페이지의 다낭 관광지, 식당, 가격, 환율, 비자 기간, 날씨, 병원·긴급 연락처, 항공편 등 지역·시간 의존 정보
- Wikimedia 사진, 외부 지도, 외부 이미지 URL 및 지도 타일
- 참조 페이지의 HTML/CSS/JavaScript, 아이콘 SVG, 레이아웃 코드 및 문구의 복제
- 자동 예약·길찾기·브라우저 열기·Calendar 기록·외부 정보 수집
- 비용 정산/분할결제 기능의 즉흥적 추가

## 구현 전제

- TripPilot은 모든 여행 데이터를 Room에 로컬 저장한다.
- 기본 체크리스트 추가는 여행 범위 선택에 따른 로컬 템플릿 적용일 뿐, 외부 사실 검증이 아니다.
- AI 제안은 기존처럼 구조화된 초안으로만 들어오며, 어떤 항목도 자동 저장·실행하지 않는다.
- 사용자가 링크 열기, 지도 열기, Calendar 쓰기, 파일 import/export를 명시적으로 승인해야 한다.
