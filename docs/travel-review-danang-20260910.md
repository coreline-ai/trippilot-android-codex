## 우선 예약·확인 목록

1. 왕복 항공편 `VN431/VN430`의 실제 운항일·터미널·수하물·좌석과 귀국 공항 도착 시각.
2. 호텔 주소/체크인·체크아웃·디파짓 방식과 공항 왕복 이동.
3. 바나힐 입장권, 왕복 차량, 우천·강풍 시 취소/변경 정책.
4. 호이안 왕복 교통, 투본강 보트의 구명조끼·요금·귀환 픽업 장소.
5. eSIM/Grab/해외결제카드/여행자보험과 여권 유효기간.
